\section{Выводы}

В результате выполнения работы было изучено создание процессов в 2 ОС и способ их общения через pipe'ы.
Хотелось бы отметить три вещи, которые были узнаны в ходе выполнения работы:
\begin{itemize}
  \item Функции для работы с процессами в POSIX куда более удобные и читаемые, чем в Windows (меньше параметров, не надо просматривать документацию долгое время)
  \item В стандартной библиотеке Windows существует значительный набор собственных типов (DWORD, HANDLE...)
  \item Система LaTeX не переносит символ \_
\end{itemize}
