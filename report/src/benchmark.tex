\section{Результаты}

В результате выполнения лабораторной работы была полученна программа, работающая с системными вызовами через общий интерфейс для ОС POSIX и Windows, расширяемая под другие системы, если потребуется.

В программе создаётся несколько процессов, общающихся через pipe, для совместной обработки входных данных.
